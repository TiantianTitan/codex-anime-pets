# Diluc — 2D edition

Diluc in his original black coat, with crimson hair, red eyes and a low ponytail.

This transparent, lossless WebP v2 atlas contains nine animation states, a neutral pose and sixteen look directions. Package ID: `diluc`.

## Install

Extract the ZIP into one pet folder, keeping `pet.json` and `spritesheet.webp` directly together:

- Linux / macOS: `~/.codex/pets/diluc/`
- Windows: `%USERPROFILE%\.codex\pets\diluc\`
- Custom location: `$CODEX_HOME/pets/diluc/`

Do not add a wrapping folder inside `diluc`. Select Diluc in the Codex desktop app's pet picker; refresh or restart if your app version requires it. Installation is separate from the package validation performed for this release.

Custom pet packages are intended for the Codex desktop app. Codex mobile does not display these pets; mobile installation and cross-device pet syncing are not supported.

## Playback

The atlas follows the v2 format. Which actions and look directions appear depends on the installed desktop version and its event triggers; including a pose does not make every client trigger it.

The installed client version was not verified for this release. Local previews use source-table durations, not a measured current-client schedule. Package validation uses a temporary isolated pet directory and does not install or test Diluc in the user's live app.
