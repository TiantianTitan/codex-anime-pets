# Arlecchino — 2D edition

Arlecchino in her white, black and crimson formal coat, with silver hair, a dark fringe and red cross-shaped pupils.

A transparent, lossless WebP v2 atlas with nine animation states, a neutral pose and sixteen look directions. Package ID: `arlecchino`.

## Install

Extract the ZIP into one pet folder, keeping `pet.json` and `spritesheet.webp` directly together:

- Linux / macOS: `~/.codex/pets/arlecchino/`
- Windows: `%USERPROFILE%\.codex\pets\arlecchino\`
- Custom location: `$CODEX_HOME/pets/arlecchino/`

Keep these files directly inside `arlecchino`, without another wrapping folder. On the documented desktop version `26.1007.21434`, open Settings → Pets, refresh the list, select Arlecchino, then use `/pet`. Menus and commands may differ in other versions.

Custom pet packages are for the Codex desktop app. Codex mobile does not display these pets; mobile installation and cross-device pet syncing are not supported by this package.

## Playback

The atlas follows the v2 format. Available poses do not guarantee that every desktop version will trigger every action or look direction; playback depends on the app's event handling.

The local desktop package was identified as version `26.1007.21434`. Its playback schedule was not measured during this release. Local previews use source-table durations and repeat for inspection; they do not reproduce the client's state transitions or repeat limits. Package validation uses a temporary isolated pet directory. It does not install or test Arlecchino in the user's live app.
