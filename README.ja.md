## Codex v2 仕様

| 項目 | 内容 |
| --- | --- |
| アトラス | 8 列 × 11 行、`1536×2288` |
| セル | `192×208` |
| 状態 | 待機、右移動、左移動、手振り、ジャンプ、失敗、入力待ち、作業中、レビュー |
| 視線 | 時計回りの 16 方向 |
| 透過 | 未使用セルを整理した RGBA WebP |
| バージョン | `spriteVersionNumber: 2` |
