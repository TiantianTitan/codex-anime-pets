# Caesar King — 2D edition

Caesar in her black-and-red biker outfit, with sage-gray hair, amber eyes and her mechanical left arm.

A transparent, lossless WebP v2 atlas with nine animation states, a neutral pose and sixteen look directions. Package ID: `caesar-king`.

## Install

Extract the ZIP into one pet folder, keeping `pet.json` and `spritesheet.webp` directly together:

- Linux / macOS: `~/.codex/pets/caesar-king/`
- Windows: `%USERPROFILE%\.codex\pets\caesar-king\`
- Custom location: `$CODEX_HOME/pets/caesar-king/`

Do not add another wrapping folder inside `caesar-king`. On the documented desktop version `26.1007.21434`, open Settings → Pets, refresh the list, select Caesar King, then use `/pet`. Menus and commands may differ in other versions.

These custom pet packages are for the Codex desktop app. Codex mobile does not display these pets; mobile installation and cross-device pet syncing are not supported by this package.

## Playback

The atlas follows the v2 format. Available poses do not guarantee that every desktop version will trigger every action or look direction; playback depends on the app's event handling.

The local desktop package was identified as version `26.1007.21434`. Its playback schedule was not measured during this release. Local previews use source-table durations and repeat for inspection; they do not reproduce the client's state transitions or repeat limits. Package validation uses a temporary isolated pet directory and does not install or test Caesar in the user's live app.
