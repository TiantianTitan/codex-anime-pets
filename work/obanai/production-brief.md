# Obanai 2D production brief

- Deliverable: one Codex-compatible animated pet, 2D only.
- Pet id: `obanai`.
- Display name: `伊黑小芭内 Obanai`.
- Visual style: crisp 2D chibi sticker with bold outline and restrained cel shading.
- Source references: four user-provided images reviewed; the two strongest identity references are attached to generation jobs.
- Required atlas: RGBA WebP, 1536×2288, 8 columns × 11 rows, 192×208 cells, `spriteVersionNumber: 2`.
- Required motion: nine standard rows plus sixteen clockwise look directions with explicit cardinal anchors.
- Packaging scope: local output directory and zip archive only. Do not install, upload, publish, or generate a 3D variant.
