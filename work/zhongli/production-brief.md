# Zhongli 2D production brief

- Deliverable: one Codex-compatible animated pet, 2D only.
- Pet id: `zhongli`.
- Display name: `Zhongli 钟离`.
- Visual style: polished 2D chibi anime sticker with clean dark-brown outlines and restrained soft cel shading.
- Source references: four user-provided images reviewed; the strongest full-body and face references are attached to generation jobs, with one supporting identity view used only when the five-input limit permits.
- Required atlas: RGBA WebP, 1536×2288, 8 columns × 11 rows, 192×208 cells, `spriteVersionNumber: 2`.
- Required motion: nine standard rows plus sixteen clockwise look directions with explicit cardinal anchors.
- Packaging scope: local project output directory and zip archive only. Do not install, upload, publish, or generate a 3D variant.
