# Running-left derivation decision

`running-left` must be generated independently rather than mirrored from `running-right`.

Burnice's thigh straps, jacket/flame accents, goggles, and close-fitting fuel backpack contain side-specific visual information. A deterministic mirror would move these identity cues to the wrong side, so the leftward gait uses the approved rightward row only as cadence evidence while preserving the canonical outfit construction.
