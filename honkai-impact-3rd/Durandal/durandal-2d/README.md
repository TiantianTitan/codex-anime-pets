# Durandal — 2D edition

Durandal in her blue summer outfit, with peach-tipped blonde hair, blue eyes and orange sunglasses resting on her forehead.

A transparent, lossless WebP v2 atlas with nine animation states, a neutral pose and sixteen look directions. Package ID: `durandal`.

## Install

Extract the ZIP into one pet folder, keeping `pet.json` and `spritesheet.webp` directly together:

- Linux / macOS: `~/.codex/pets/durandal/`
- Windows: `%USERPROFILE%\.codex\pets\durandal\`
- Custom location: `$CODEX_HOME/pets/durandal/`

Keep these files directly inside `durandal`, without another wrapping folder. On the documented desktop version `26.1007.21434`, open Settings → Pets, refresh the list, select Durandal, then use `/pet`. Menus and commands may differ in other versions.

Custom pet packages are for the Codex desktop app. Codex mobile does not display these pets; mobile installation and cross-device pet syncing are not supported by this package.

## Playback

The atlas follows the v2 format. Available poses do not guarantee that every desktop version will trigger every action or look direction; playback depends on the app's event handling.

The local desktop package was identified as version `26.1007.21434`. Its playback schedule was not measured during this release. Local previews use source-table durations and repeat for inspection; they do not reproduce the client's state transitions or repeat limits. Package validation uses a temporary isolated pet directory. It does not install or test Durandal in the user's live app.
