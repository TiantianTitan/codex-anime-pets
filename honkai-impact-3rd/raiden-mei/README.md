# 雷电芽衣 Raiden Mei — Codex Pet v2

本目录包含两个可独立使用的 Codex v2 桌面宠物包：

- `raiden-mei-2d/`：清晰贴纸感 2D Q 版。
- `raiden-mei-3d/`：精致 PVC/手办感 3D Q 版。

每个包都只依赖目录内的 `pet.json` 与 `spritesheet.webp`。图集规格均为 RGBA WebP、1536×2288、8×11 网格、192×208 单元格，`spriteVersionNumber` 为 2；包含 9 个标准动画状态和 16 个顺时针观察方向。

`qa/` 提供两种风格的标准动作接触表、16 向检查表和结构校验报告，方便人工抽检。原始 GIF 保留在本目录顶层。

本次仅生成本地成品与压缩包，没有安装到 Codex 用户目录，也没有发布或上传。
