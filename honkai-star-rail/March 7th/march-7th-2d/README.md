# March 7th — 2D edition

March 7th in her blue-and-white outfit, with pink hair, bright two-tone eyes and a camera at her hip.

This transparent, lossless WebP v2 atlas contains nine animation states, a neutral pose and sixteen look directions. Package ID: `march-7th`.

## Install

Extract the ZIP into one pet folder, keeping `pet.json` and `spritesheet.webp` directly together:

- Linux / macOS: `~/.codex/pets/march-7th/`
- Windows: `%USERPROFILE%\.codex\pets\march-7th\`
- Custom location: `$CODEX_HOME/pets/march-7th/`

Do not add a wrapping folder inside `march-7th`. Select March 7th in the Codex desktop app's pet picker; refresh or restart if your app version requires it. Installation is separate from package validation.

Custom pet packages are intended for the Codex desktop app. Codex mobile does not display these pets; mobile installation and cross-device pet syncing are not supported.

## Playback

The atlas follows the v2 format. Which actions and look directions appear depends on the installed desktop version and its event triggers; including a pose does not make every client trigger it.

The installed desktop package was identified as version `26.1007.21434`. Its playback schedule was not measured during this release. Local previews use source-table durations, not a verified current-client schedule. Package validation uses a temporary isolated pet directory and does not install or test March 7th in the user's live app.
